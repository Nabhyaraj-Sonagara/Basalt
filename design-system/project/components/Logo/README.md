# Logo

The Basalt lockup: the honey-capped column mark plus the lowercase wordmark "basalt" set live in `display`. Use it in the app's top-left, onboarding and marketing; use `basalt-app-icon.svg` (Logos) for dock, favicon and store tiles.

- Props: `size` (mark height in px, default 32; the wordmark scales to 0.78×), `wordmark` (default true; false shows the mark alone).
- Place on `surface`, `surface-raised` or `surface-sunken`. On `stone` or `honey` grounds use the mono mark from Logos instead.
- Don't: retype the wordmark in another face, capitalise it, add a tagline inside the lockup, or animate the mark.
