# Kbd

A key cap for shortcuts in menus, tooltips, the palette footer and docs. One key per Kbd; separate a chord with a space, not "+": `⌘` `K`.

- Children: the key glyph or name (`⌘`, `⇧`, `↵`, `esc`, `[[`). Mac glyphs on macOS, `Ctrl` spelled out elsewhere.
- Always beside a text description; a shortcut alone is not a label.
