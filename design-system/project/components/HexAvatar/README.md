# HexAvatar

Initials in a pointy-top hexagon, for hives, people in shared hives and plugin authors. Never a circle.

- Props: `name` (initials are its first two words), `label` (override the initials), `size` (width in px; height is size × 1.1547), `tone` — `honey` (the current hive or you), `stone` (other people), `wax` (other hives you belong to).
- Provide `name` always: it becomes the accessible label.
