# HexAvatar

Initials in a pointy-top hexagon, for vaults, people in shared vaults and plugin authors. Never a circle.

- Props: `name` (initials are its first two words), `label` (override the initials), `size` (width in px; height is size × 1.1547), `tone` — `honey` (the current vault or you), `stone` (other people), `wax` (inactive vaults).
- Provide `name` always: it becomes the accessible label.
