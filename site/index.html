Markdown notes, built for AI

Basalt keeps your notes as plain Markdown files in a folder you own. Link them, search them by meaning, and let Claude, ChatGPT, Gemini or a local model work in them with you.

Download Basalt

For macOS, Windows and Linux. Free and open source.

Write and link

Live preview that shows Markdown syntax only where your cursor is. [[Links]], embeds, callouts, tasks, math and diagrams. Rename a note and every link follows.

Find anything

Search with operators or by meaning, related notes, backlinks, tags, properties and table views. The comb view lays your links out on a honeycomb.

Work with AI

An assistant that reads the note you're in and the rest of your hive. A built-in MCP server and CLI let agents search, read and write notes, with no delete tool.

Yours, on disk

A hive is any folder of Markdown files. Open the one you already have. Basalt's own settings live in .basalt/, and nothing leaves your computer unless you choose a cloud model.

Opening Basalt the first time

Basalt isn't code-signed yet, so your system asks once before opening it.

macOS
Drag Basalt to Applications and open it. When macOS says it can't verify the developer, open System Settings → Privacy & Security, scroll down and click Open Anyway.
Windows
Run the installer. If SmartScreen appears, click More info → Run anyway.
Linux
Install the .deb with sudo apt install ./Basalt-*.deb, or make the AppImage executable with chmod +x Basalt-*.AppImage and run it.

After that, Basalt updates itself on Windows and Linux. On macOS it tells you when a new version is ready to download.
